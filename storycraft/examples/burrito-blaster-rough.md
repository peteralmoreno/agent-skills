# Burrito Blaster

Need a nicer single-page HTML to explain our pretend lunch-delivery simulation. It's a fun example, **not a real app**. Make it understandable to a person seeing it for the first time.

Flow: Check order -> Prepare a burrito -> Find imaginary customer -> Simulate launch -> Record notification -> Done.

But there are other endings. Missing order? Pause. Ingredients not available? Stop. Unknown address, uncertain landing, or notification unavailable? Pause. Keep these routes. Don't imply anything happens in real life.

We should show the idea quickly, let someone click around to understand the steps, and say what an example result would include: pretend order reference, checked fake coordinates, imagined delivery result, simulated notification result. No real stats, receipts, customers, launches, or messages.

Give it personality, but make it still clear enough for a technical teammate to understand. All content and interactions should work offline. Try all 3 styles: dark, morrito, gilded.
