# Request fresh Copilot review

Confirm the desired remote head and record why review is needed. Use the supported Copilot review/re-review action available for this repository. Don't substitute a generic human review request or claim an ordinary comment triggered Copilot.

Before requesting, reconcile existing review requests and worklog receipts. If a matching request already exists, do not duplicate it. Record the head, request time, and returned reference; choose **requested or already requested**. A request acknowledgment is not a completed review. Later inspection must check review completion and findings for the intended changes.

If Copilot is unavailable, access is missing, or delivery of the request cannot be established, choose **unavailable or uncertain** and provide the exact manual action or decision needed. Don't silently waive review.
